# Changelog 63 - Crossminal Compact Tab Close Controls & Proportional Sizing

### Highlights & Modifications
1. **Crossminal Tab Close Button Proportions**:
   - Replaced default GTK button sizing with `.tab-close-btn` class (`min-height: 16px`, `min-width: 16px`, `padding: 0 3px`, `font-size: 11px`).
   - The tab close button `[×]` is now sleek, compact, and aligned cleanly with the tab text label instead of a bulky square box.
2. **Keyboard Mapping & Super Key Documentation**:
   - Clarified that `Super` in shortcuts refers to the **Windows Key** (`⊞ Win` / Command).
   - `Super+L` locks session, `Super+I` launches Crossings settings, `Super+P` projects/mirrors displays.
